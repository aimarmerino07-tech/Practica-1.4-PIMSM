# Practica-1.4-PIMSM
Practica 1.4 DASP - Aimar Merino

Resumen
Aplicación web simple para crear, editar, eliminar y filtrar notas por prioridad. Las notas se guardan en localStorage.

Instalación
1. Clona el repositorio.
2. Abre index.html en el navegador o sirve con un servidor local.

Estructura
- index.html Interfaz.
- styles.css Estilos.
- app.js Lógica.

Ramas
- main rama estable.
- develop rama de integración.
- feature/* ramas para funcionalidades.

Convenciones de commits
- feat: nueva funcionalidad.
- fix: corrección de errores.
- chore: tareas de mantenimiento.

Cómo probar
1. Crear nota, recargar, comprobar persistencia.
2. Filtrar por prioridad.
3. Editar y eliminar notas.
