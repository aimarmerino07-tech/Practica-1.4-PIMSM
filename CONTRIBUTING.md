# Contribuir

Flujo
1. Crea una rama desde develop: feature/nombre-descriptivo.
2. Haz commits pequeños y descriptivos.
3. Abre PR desde feature/* -> develop.

Plantilla de PR
- Título: feat: descripción corta
- Descripción:
  - Objetivo:
  - Cambios:
  - Cómo probar:
- Checklist:
  - [ ] Lint pasado
  - [ ] Pruebas manuales
  - [ ] Documentación actualizada
